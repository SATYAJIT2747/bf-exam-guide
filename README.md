# Business Fundamentals: Exam Guide

A one-page revision guide for the Business Fundamentals end-semester exam (case/scenario-based, closed book).

Open `index.html` in a browser, or view it on GitHub Pages.

It covers:
- Finance ratios and business-case maths (NPV, IRR, TCO, real options, unit economics)
- Strategy: Five Forces, VRIO, Blue Ocean, dynamic capabilities
- Customer-centric product design: Kano, QFD / House of Quality, Hook Model
- Quality management, vendor management and contracts
- Decision making, leadership in a VUCA world, management theories, innovation
- Worked model answers to the 2025 paper's cases, a "which framework when" table and a last-hour revision sheet
